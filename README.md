## ⚡ mini_redis

A lightweight asynchronous in-memory key-value database and cache built from scratch to explore how systems like Redis work internally.

The project explores networking, TCP communication, asynchronous programming, protocol handling, and persistence.

**Tech:** Rust • Tokio • TCP • RESP2 • Systems Programming
